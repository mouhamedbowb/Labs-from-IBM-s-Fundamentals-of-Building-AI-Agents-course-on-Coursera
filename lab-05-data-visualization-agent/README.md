# Lab 5 — Build Your Own Data Visualization Agent

Part of [AI Agents with LangChain — Coursera Labs](../). From **Module 3: Using Built-in Agents in LangChain** of IBM's [Fundamentals of Building AI Agents](https://www.coursera.org/learn/fundamentals-of-building-ai-agents) course.

## What this lab covers

- Using LangChain's `create_pandas_dataframe_agent` so a CSV dataset can be explored entirely in plain language
- Asking for scatter plots, bar charts, and heatmaps and getting the chart back directly in the notebook
- Inspecting the actual pandas/plotting code the LLM generated behind the scenes to produce each chart

## Tech stack

Python · LangChain · IBM watsonx.ai · pandas · Matplotlib · Seaborn

- [`data_visualization_agent.ipynb`](./data_visualization_agent.ipynb) — the completed notebook
